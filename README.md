# ClarityPath

© 2026 Julian Minko · Architect of MAYHEM · ClarityPath.

Public New South Wales legal-information catalogue and owner-controlled case workspace.

For a new owner’s installation, start with the [readable manual and artificial intelligence setup guides](setup.html), including accounts, costs, permissions and privacy before the steps. [AI-SETUP.txt](AI-SETUP.txt) and [MANUAL-SETUP.txt](MANUAL-SETUP.txt) are the complete copy/download versions. The receiving artificial intelligence is instructed to complete that owner’s own public application repository, separate private encrypted case store, required artificial intelligence deployment/connections, recovery arrangements and live verification. Root [AGENTS.md](AGENTS.md) carries the same routing instruction for agents opening a clone. Use the source author’s repository as a reference and verify the new owner’s destination before pushing.

Choose **Set up my system** on Home for the six-stage guided installation, or **Installation** inside the workspace. It uses the existing connection and export forms, labels verified checks separately from owner confirmations and prepared downloads, and compares an encrypted backup locally without replacing current work. Progress lasts for the current open session; lock or refresh starts a new checklist. The full manual and assisted directions remain available. Run npm run test:installation with the other relevant checks; its controlled services do not establish live owner connections.

Private MAYHEM specifications supplied for building this project are private inputs. They must not be committed, published, included in public source libraries/packs or appended to provider requests. Creator authorisation to use a private build input is not redistribution permission.

Run node scripts/package-release.mjs, then npm test. The generated site/ directory is the only publication artifact. The public Build page and build-pack.txt reproduce only the named public application files. See claritypath-public-build.txt and OPERATING-GUIDE.txt.

Private GitHub storage and required artificial intelligence service need the actual owner’s configuration. No real case data or credentials are bundled. The public catalogue, install manifest, icons and public-only offline shell work independently of a saved case.

The required artificial intelligence deployment and configuration-only connection check are described in service/README.txt. The service can run on a Node.js host or from service/Dockerfile; the public site stays on GitHub Pages. Readiness checks never count as a live provider test.

Protected selected handoffs use handoff.html for local recipient unlocking. The recipient needs the exported file and its separate passphrase; no private workspace account is required. The recovered ZIP is readable and must be stored privately.

Installed launch and return open Home. Workspace entry is deliberate; returning Home retains the current workspace and unfinished form in memory. File selection and open review dialogs retain their task. Home is not private saving or backup. Generate app/home-view.mjs from the public index.html through the package command, and retain app/startup.mjs, the shared navigation module, styles and public offline-cache entries. Run npm run test:launch along with the core, workflow, offline, navigation and support-page checks. The launch checks simulate installed mode and foreground return; report a physical-phone result only if performed.
